¿Qué es Mercado Eficiente?

Mercado Eficiente (mercadoeficiente.cl) es una herramienta de Geopolis Consultores para consultar licitaciones públicas de Chile a través de la API pública de Mercado Público (ChileCompra). Esta política explica qué datos recopilamos y cómo se usan.

Datos que recopilamos
  • Código de licitación buscado: se envía a nuestro servidor para consultar la API de Mercado Público. No se almacena.
  • Correo electrónico: si usas "Alertas de Cierre" o "Avisar Resultado", el correo que ingresas se usa únicamente para enviarte ese aviso puntual, a través del proveedor EmailJS. No lo almacenamos en una base de datos ni lo usamos para otro fin.
  • Datos de navegación: como la mayoría de los sitios web, terceros (ver abajo) pueden recopilar datos técnicos de tu visita (tipo de navegador, dispositivo, páginas vistas) con fines de publicidad y analítica.
Publicidad — Google AdSense

Este sitio muestra anuncios de Google AdSense. Google, como proveedor externo, usa cookies para mostrar anuncios en base a visitas anteriores de un usuario a este u otros sitios. El uso de cookies de publicidad por parte de Google permite mostrar anuncios personalizados a los visitantes.

Puedes inhabilitar la publicidad personalizada visitando la Configuración de Anuncios de Google, o (para terceros en general) www.aboutads.info.

Independencia

Mercado Eficiente es un proyecto independiente, no afiliado ni respaldado por ChileCompra ni Mercado Público. Los datos de licitaciones mostrados provienen de su API pública oficial.

Contacto

Para consultas sobre esta política o tus datos, contáctanos a través de Geopolis Consultores.
